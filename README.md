# Lecteur surround

Lecteur vidéo (Python + mpv) avec upmix surround de type Dolby Pro Logic II (approximation).

## Obtenir l'exécutable
- **Manuel** : onglet *Actions* > *Build Windows exe* > *Run workflow*, puis télécharger l'artefact `LecteurSurround-windows`.
- **Release** : `git tag v1.0 && git push --tags` ; le zip apparaît dans *Releases*.

Dézipper puis lancer `LecteurSurround\LecteurSurround.exe`.

## Utilisation
Configurer la sortie audio Windows en 5.1, ouvrir une vidéo, choisir le mode audio dans le menu déroulant.
